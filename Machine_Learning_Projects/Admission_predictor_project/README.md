# 🎓 Admission Predictor – Streamlit Deployment

This project predicts the **chance of student admission** to universities based on their academic profile using Machine Learning models.

---

## 🚀 **Project Overview**

✅ Built a regression model to predict **Chance of Admit** based on:

- GRE Score
- TOEFL Score
- University Rating
- SOP Strength
- LOR Strength
- CGPA
- Research Experience

✅ **Models Used:**

- Multiple Linear Regression
- Random Forest Regressor

✅ **Best Model Performance:**

- **R² Score:** ~76%
- **MAE:** 0.07
- **RMSE:** 0.10
